# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner through a verified contact method listed on the owner's GitHub profile.

## Scope

TransferETA is planned as a static client-side calculator. It should not request or upload user files, collect credentials, or require server-side secrets. Security reports about unexpected network requests, unsafe rendering, dependency vulnerabilities, or privacy behavior are in scope.

## Supported versions

Security support begins with the first published stable release. The current supported version will be stated here after v1.0.0 is published.
