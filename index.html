GOOD TO KNOW

Questions, answered.

A few helpful details to make your estimate more useful.

What's the difference between Mbps and MB/s?

Mbps means megabits per second, while MB/s means megabytes per second. One byte contains eight bits, so 1 MB/s equals 8 Mbps when using decimal units. Internet plans are usually advertised in Mbps, while file transfer dialogs often show MB/s.

Why can my real upload take longer than this estimate?

The calculator models a steady payload rate. Real transfers can be affected by Wi-Fi signal quality, network congestion, server upload limits, protocol overhead, retransmissions, and other devices using the connection. Treat the result as a planning estimate, not a guarantee.

Should I add a throughput reduction if I used a speed test?

Usually, no. A speed test normally reports measured throughput after many real-world conditions have already affected the result. Keep the reduction at 0% unless you have a specific additional loss you want to account for.

Does TransferETA upload or inspect my files?

No. TransferETA only uses the size and speed values you type in. It does not ask you to select a file, read file contents, or transfer anything. All calculations run locally in your browser.

What does the simulation do?

The preview animates progress over a time-scaled clock using the estimate. It is not connected to your network and does not upload a real file. You can change the preview pace, pause, resume, or reset it.

Are GB and GiB the same?

No. GB is decimal and equals 1,000,000,000 bytes. GiB is binary and equals 1,073,741,824 bytes. TransferETA supports both conventions so your estimate matches the units you are using.
